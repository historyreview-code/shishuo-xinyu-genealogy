# 世说新语 · 魏晋风流人物谱系图

「王谢两大家族为主轴 · 竹林七贤 · 名士交游」的交互式人物谱系图，为「世说新语」短剧系列配套。

- **33 位人物** · **36 条关系**（父子/兄弟/叔侄/夫妻·王谢联姻/交游/决裂）
- 纯前端 SVG 手绘，零依赖，离线可用
- 深色/浅色主题切换 · 滚轮缩放 · 拖拽平移 · 点击人物看小传
- 金环「剧」徽 = 已拍短剧出场人物
